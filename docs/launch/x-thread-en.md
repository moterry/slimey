**1/ (with video)**

I made a tiny pixel slime that lives on my Mac and watches my Claude usage.

It shows how much of my session is left, glows blue while Claude Code works, turns green when it's done, and melts into a puddle at 100%.

Free and open source ↓

---

**2/**

Why: I kept hitting my Claude limit in the middle of a task, and kept losing track of which Claude Code session had finished.

Now one glance at the corner of my screen answers both.

---

**3/**

The task light runs on Claude Code hooks:

🔵 working
🟡 blinking: waiting for you (a permission or a question)
🟢 done

In the desktop app, green only goes out once you actually open that session, so a finished task never slips by unread.

---

**4/**

It's a native Swift/AppKit app, about 1 MB, with no server and no telemetry. It only talks to claude.ai, using your own login.

Unofficial fan project: it relies on undocumented endpoints, so it may break.
