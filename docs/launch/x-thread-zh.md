**2/**

起因：经常做到一半撞上 Claude 的额度上限，也经常忘了哪个 Claude Code 会话已经跑完了。

现在瞄一眼屏幕角落，两件事都清楚了。

**3/**

任务灯靠 Claude Code 的 hooks 实现：

🔵 正在干活
🟡 闪烁：在等你确认权限或回答问题
🟢 跑完了

在桌面 App 里，只有你真的点开那个会话，绿灯才会熄灭，跑完的任务不会被漏看。

---

**4/**

原生 Swift/AppKit 写的，大约 1 MB。没有服务器，不上报任何数据，只用你自己的登录访问 claude.ai。

这是非官方的粉丝项目，依赖未公开的接口，以后可能会失效。
