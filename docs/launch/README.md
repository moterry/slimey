## Before posting

1. Create the GitHub repo `moterry/slimey`, push, and publish release `v0.1.0` with `dist/Slimey-0.1.0.zip`.
2. Repo settings:
   - **Description:** A tiny pixel slime on your Mac that shows your Claude usage and lights up when Claude Code finishes.
   - **Topics:** `claude`, `claude-code`, `macos`, `desktop-pet`, `pixel-art`, `swift`, `appkit`, `menubar`
   - **Social preview:** upload `media/slimey-poster-en.png`.
3. Download the release zip yourself on a clean path and walk through the README install steps once.

## Posting tips

- Upload the video natively; don't link to it. Keep the GitHub link in a reply.
- Pin the thread on your profile while it's your newest project.
- In the first hour, reply to everyone who comments; that is when X decides how far to push a post.
- Don't post all platforms at the same minute. Do X first, then 小红书/即刻 a few hours later, and V2EX the next day, so you can fix anything people report.
- Keep a simple log of each launch (views, profile visits, new followers, stars after 24h and 7 days). After 3–4 products you'll see which kind of post works for your audience.
