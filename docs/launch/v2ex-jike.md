# V2EX（发在“分享创造”节点）/ 即刻

**标题：** [开源] Slimey：一只盯着 Claude 用量、Claude Code 跑完会亮灯的 Mac 桌面像素史莱姆

**正文：**

做了个小东西，自己用了一个多月，整理后开源了。

- 头顶显示当前 Claude session 用了多少、几点重置；点一下可以看本周额度
- 颜色跟着用量变：绿 → 黄 → 红（冒汗）→ 100% 化成一滩睡着了
- 接上 Claude Code hooks 之后，有会话在跑亮蓝灯，在等你确认闪黄灯，跑完了亮绿灯
- 绿灯只有在你真的点开了那个会话后才会熄灭（读的是桌面 App 本地记录的会话聚焦时间）

技术上：原生 Swift + AppKit，没有任何依赖，不需要 Xcode 工程，`swiftc` 直接编译；演示视频也是用 App 自己的绘制代码逐帧渲染出来的。

用量是用你自己的登录状态请求 claude.ai 用量页的同一个接口拿到的，属于非官方用法，以后可能会失效，介意的话请先看一下 Anthropic 的条款。

GitHub: https://github.com/moterry/slimey

欢迎提意见，也欢迎 PR。
