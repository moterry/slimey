天天用 Claude 写代码的人应该懂：
做到一半突然撞上额度上限😵
开了好几个 Claude Code 会话，忘了哪个已经跑完了

所以我做了一只住在 Mac 桌面上的像素史莱姆👇

🟢 头顶显示 Claude 用量和重置时间
🎨 用得越多颜色越红，80% 以上开始冒汗，到 100% 直接化成一滩睡着了
💡 Claude Code 在干活亮蓝灯，干完变绿灯，等你确认时闪黄灯
👀 只有你真的点开了跑完的会话，绿灯才会熄灭

原生 Mac 应用，大约 1 MB，不上传任何数据，免费开源。
GitHub 搜 moterry/slimey
